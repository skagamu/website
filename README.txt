SKAGAMU DIGITAL BRANDING - FRONTEND
====================================
Prototype frontend statis.

Cara menjalankan:
1. Extract ZIP.
2. Buka index.html di browser.
3. Untuk pengembangan, edit assets/css/style.css dan assets/js/app.js.

Catatan:
Versi ini adalah paket frontend yang dapat langsung dibuka sebagai prototype.
Backend, database, login admin, upload karya siswa, dan hosting belum termasuk.
